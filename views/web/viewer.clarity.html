{# The `vimg.cgi` image viewer. Port of the legacy inline heredoc. Opened in its own small window from a thumbnail. There is no site frame: the page is a black field with a blue-bordered box, the image on top and a caption row. Clicking the image calls GoBack(), which returns to the page that opened the window (or closes it when it was the first one). Kept as a bare fragment, like `web/muses` - it sets its own colours and must not inherit `views/layouts/page.clarity.html`. #} {{ title }}
