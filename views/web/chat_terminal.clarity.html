{# The chat terminal - production `https://hbr1.com/chat/`. Production is a with rows 26,*,26,29 and columns 64,*,100,64. The port keeps that geometry but not the frameset: a frameset's row heights are frameset units that CSS cannot reach, so they stay at 26/29 raw pixels while the frames inside scale - which clipped the submit bar and sliced the "MESSAGE TERMINAL" heading in half once the site switched to a 1.333 zoom. A CSS grid with the same numbers as tracks, in ONE document, scales as a whole. Each pane is a nested scrolling box, which is what a frame was. The four chrome panes are the static files shipped under /chat/. They are loaded through iframes rather than inlined so the files stay the single source of truth, exactly as the legacy frameset referenced them. The panes keep production's `name` attributes, so the `target` the legacy `/chat/bottom.htm` chrome and the message pane's links use still resolve. Nothing else needs them: `/chat` is only ever loaded as its own document (`/chat/` is the navigation map's `target="main"`), never inside another frame, so there is no cross-frame `updatePage()` handshake to preserve. #} Chat Terminal - HBR1
