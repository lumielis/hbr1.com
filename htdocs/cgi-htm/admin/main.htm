The NCSA compatible log file parser is running!
For three days i tried to install a piped log-app, but i found no way, so all functions are stored in perl file ../ssms/access.pl
All entries in apache's access log will be resolved, converted and saved to mysql on every script call
The log is empty after every call, all entries are available in xxx.sav
If a new user (ip) is visiting the site, its information will be taken from whois server (maybe slow sometimes)
