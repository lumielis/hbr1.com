U-Upload Lite is a file upload applet that runs in a web page.  Powered by Unlimited FTP, the 
popular Java based FTP applet, U-Upload Lite provides one of the fastest ways to upload
files on the internet.  U-Upload Lite does not require a special server program or CGI in order 
to run like other upload components.  It will connect to any standard FTP server, giving you full
control over where files are stored.

U-Upload Lite is free for non-commercial use as described in LICENSE.TXT

This is the version 1.1 of U-Upload Lite released on November 13, 2001
Here is short list of all the features:
- Upload a single file to an FTP server
- Progress dialog with cancel button
- Specify the remote directory to which files will be sent 
- Change background color to match your site
- Multiple language support

Installation Instructions for U-Upload Lite.

IMPORTANT!!! If you currently already have a running version of U-Upload Lite,
then you can just overwrite the .cab and .jar files with these new files.
